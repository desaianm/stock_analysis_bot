Bottlenecks, ranked by impact

critical

Reddit is the only discovery source

The screening agent's prompt opens with "PRIORITY INTELLIGENCE: Recent Reddit Community Insights". Every ticker the agent considers came from a recent r/Baystreetbets or r/wallstreetbets post. If Reddit is quiet that day, or only retail-momentum names are trending, the entire run is biased toward speculative micro-caps.
Symptom: runs #15-#17 surfaced tickers like RX.V, SCD.V, DMX.V, ABXX.NE — all micro-cap Canadian names. The fundamental universe (S&P 500, TSX Composite, Russell 1000) is never scanned.
critical

Hard screen rejects after the agent picks — wasted reasoning

The agent spends ~2 min producing a multi-page screening report. Then _hard_screen_report_candidates rejects most/all of the picks because they fail simple numeric tests (current ratio < 1.5, debt/equity > 2.0, P/E > 25). The agent's reasoning is discarded.
Reverse the order: filter the universe first (cheap, fast), THEN have the agent reason about the survivors. Current order wastes API spend.
critical

P/E < 25 is meaningless without sector context

Banks trade at P/E 8, SaaS at 50, utilities at 18. A flat P/E gate either rejects entire industries or accepts overpriced names in cheap sectors. Same problem for P/B, debt/equity, current ratio.
Need sector-relative percentile ranking. "Bottom quartile P/E in its sector" is a real value signal; "P/E < 25" is noise.
high

No insider-buying signal

Open-market insider purchases (Form 4) are one of the most-validated value signals in academic finance (Lakonishok & Lee 2001, Cohen-Malloy-Pomorski 2012). SEC publishes Form 4 free; Polygon and Financial Datasets both expose clean APIs. We have keys for both. Currently fetch zero insider data.
Adding insider buying as a discovery signal would surface stocks where management is voting with their wallets — independent of Reddit hype.
high

No intrinsic value calculation

The agent reasons about catalysts and momentum but never computes what a stock should be worth. Reverse-DCF (solve for implied growth that justifies today's price) is ~30 lines of Python — no API needed.
Without intrinsic value, "cheap" is a vibe. With it, you can say "this stock needs 18% revenue growth for 10 years to justify its price, and has been growing 4%".
medium

Regex ticker extraction is fragile

_extract_candidate_tickers_from_report expects the agent to write headings as **Company Name (TICKER)**. The agent's format drifts run-to-run; when it doesn't match, the hard-screen review section is silently empty. Run #17 produced 9 visible tickers but the regex extracted zero.
An LLM extractor (gpt-4.1-nano) is wired as a fallback — but only fires when regex returns empty. Need a deterministic output schema: agent must emit structured JSON, not prose.
low

Reddit summarizer is sequential

The Reddit discovery summarizes posts in batches of 50 sequentially with gpt-5.4-nano. With 60 posts, that's 2 sequential LLM calls. Could run in parallel via asyncio.gather.
Minor: shaves 5-10 seconds off each run. Low priority.

3. Proposed: The Quant Funnel

Flip the order. Start with a fundamental universe, narrow it deterministically through cheap numeric filters, then spend agent reasoning only on the survivors. Reddit becomes one input at the catalyst stage, not the discovery driver.

Key shift: the agent stops doing discovery (where LLMs are weak) and only does narrative thesis writing on a pre-vetted shortlist (where LLMs are strong). Reddit becomes signal, not driver.

What stays the same

  • The Agno framework, tool wrapper pattern, and JSON state files all carry over.
  • SQLite persistence schema is unchanged — same tables, same fields.
  • The turnaround-style deep dossier still runs, just on better-selected candidates.
  • The hard-screen rules still gate the final list (belt & suspenders).

6. Risks & tradeoffs

yfinance rate limits. Scanning 3,000 tickers in parallel will hit yfinance's unofficial rate limit. Mitigation: throttle to 10 concurrent calls, cache results for 24h, fall back to Polygon snapshot endpoint for bulk data.
Sector medians need a baseline. First run has no historical median data. Mitigation: compute medians from the current universe scan (live, every run) rather than from cached history — slightly more compute, no warm-up problem.
Reddit users may complain. If the bot stops surfacing the meme stocks they expected, satisfaction may drop short-term. Mitigation: keep a small "Reddit echo" section in the report listing the most-discussed tickers separately, even if none made the funnel cut.
Reverse-DCF assumptions are sensitive. Discount rate and terminal growth materially affect the implied-growth output. Mitigation: report a range (8%, 10%, 12% discount rates) rather than a single number.
